# Jibegaza MenuBar

오늘 얼마나 일했는지, 언제 퇴근할 수 있는지 macOS 메뉴바에서 확인하는 근무 시간 계산기입니다. `오늘 근무`에서 하루의 근무 계획을 세우고, `주간 시간 계산`에서 월~금의 인정시간을 합산할 수 있습니다.

## 웹 버전 주간 시간 계산기

[주간 시간 계산기 바로가기](https://jibegaza.vercel.app/)

## 앱 설치 가이드

1. 다운로드한 ZIP의 압축을 풀고 **Jibegaza MenuBar 앱을 응용 프로그램 폴더로 이동**합니다. 추후 앱 업데이트를 위해 필요한 과정입니다.
2. 앱을 처음 실행했을 때 **“‘Jibegaza MenuBar’을(를) 열지 않음”** 경고가 나타나면 **완료**를 클릭합니다.
3. **시스템 설정 → 개인정보 보호 및 보안 → 보안**에서 **그래도 열기**를 클릭합니다.

자세한 설치 방법은 다운로드한 ZIP에 포함된 설치 가이드 이미지를 참고해주세요.

## 시작하기

1. `오늘 근무`에서 출근 시각을 입력하세요. flex를 사용한다면 `flex 연결` 또는 `flex 동기화`로 출근 시각을 가져올 수 있습니다.
2. 목표 근무시간을 선택하세요. 원하는 시간이 없다면 `직접입력`에서 시간·분을 입력하세요.
3. 메뉴바 설정에서 표시할 항목을 선택하세요. 각 항목의 의미는 [남은 근무시간과 퇴근까지 남은 시간](#남은-근무시간과-퇴근까지-남은-시간)을 참고해주세요.
4. 주간 합계나 남은 요일의 근무 계획이 필요하면 `주간 시간 계산`을 이용하세요.

주간 기록만 입력해서는 오늘의 메뉴바 시간 표시가 시작되지 않습니다. 오늘 출근 시각을 입력하거나 flex 출근 기록을 동기화해주세요.

## 오늘 근무

### 목표시간과 출퇴근 시각

목표 근무시간은 휴게시간을 제외한 순수 근무시간입니다. 기본 목표는 8시간이며, `6h`, `7h`, `8h`, `9h`, `직접입력` 중에서 선택할 수 있습니다.

| 입력 방식                        | 동작                                     |
| -------------------------------- | ---------------------------------------- |
| 시간 프리셋에서 출근 수정        | 목표시간을 유지하고 퇴근 시각 계산       |
| 시간 프리셋에서 퇴근 수정        | 목표시간을 유지하고 출근 시각 역산       |
| 직접입력에서 목표 시간·분 수정   | 출근 시각을 유지하고 퇴근 시각 계산      |
| 직접입력에서 출근 또는 퇴근 수정 | 반대편 시각을 유지하고 목표 시간·분 계산 |

예를 들어 직접입력 상태에서 `09:00~18:00`의 퇴근을 `17:00`으로 바꾸면, 출근은 09:00으로 유지되고 목표시간은 휴게시간을 제외한 7시간으로 바뀝니다.

출근 시각은 **08:00부터** 입력할 수 있습니다. 07:45처럼 이전 시각을 선택하면 08:00으로 보정됩니다. 프리셋 역산 결과가 08:00 이전이면 출근을 08:00으로 맞추고, 목표시간을 유지하도록 퇴근도 다시 계산합니다.

### 주간 기록으로 목표 자동 계산

이번 주에 해당하는 주간 기록을 입력했고 **이번 주 마지막 근무일이 오늘**이라면, 주 40시간을 채우는 데 필요한 오늘 목표시간을 자동으로 제안할 수 있습니다. 연차인 날은 마지막 근무일에서 제외합니다.

자동 계산에는 오늘을 제외한 다른 요일의 필요한 근무기록이 갖춰져 있어야 하며, 휴가 인정분과 일 최대 인정시간 9시간을 반영합니다. 조건을 충족하지 않거나 계산한 목표가 0분 이하 또는 하루 인정 한도를 넘으면 자동 제안을 적용하지 않습니다.

자동 제안과 별개로 오늘 목표를 직접 정할 수 있습니다. 자동 계산이 가능한 상태에서 수동으로 변경했다면, `직접입력` 영역의 `자동계산` 버튼으로 제안값을 다시 적용할 수 있습니다.

- **직접 정하기:** 목표 프리셋을 선택하거나 `직접입력`에서 원하는 시간·분을 입력합니다.
- **자동 계산값으로 되돌리기:** 자동 제안이 가능하고 수동 목표가 적용된 상태에서 `직접입력`을 선택하면 `자동계산` 버튼이 표시됩니다. 버튼을 누르면 수동 목표 대신 주간 기록으로 계산한 목표를 적용합니다.
- **버튼이 보이지 않을 때:** 자동 제안 조건을 충족하지 않거나 이미 자동 제안값을 사용 중일 수 있습니다. 주간 기록과 오늘의 근무일 조건을 확인해주세요.

### 휴게시간과 코어타임

휴게시간은 **12:30~13:30**입니다. 근무 구간과 실제 겹치는 만큼만 제외합니다. 휴게시간을 지나지 않는 근무에는 1시간을 일괄 차감하지 않습니다.

정상근무의 코어타임은 **10:30~15:30**입니다.

- 퇴근 가능 시각은 15:30보다 빨라지지 않습니다.
- 출근 시각을 자동 역산할 때는 정상근무·반차·반반차 모두 08:00~10:30 범위를 지킵니다.
- 직접 입력한 10:30 이후 출근은 그대로 유지합니다.
- 코어타임 때문에 퇴근이 늦춰져도 직접 정한 목표시간은 늘어나지 않습니다.

오늘의 근무 유형은 `주간 시간 계산`에 입력한 해당 요일의 휴가 유형을 따릅니다. **반차·반반차·연차에는 오늘 근무의 15:30 최소 퇴근 제한을 적용하지 않습니다.** 반차·반반차도 자동 역산한 출근은 **08:00~10:30** 범위를 지키며, 휴게시간 계산은 그대로 적용합니다. 실제 지각 출근을 기록하기 위한 10:30 이후의 직접 입력은 허용합니다.

예를 들어 오후 반차로 14:00에 퇴근한다면 퇴근을 15:30으로 늦추지 않습니다. 휴가 4시간을 포함해 인정시간 8시간을 맞추려면 **09:00~14:00 중 휴게 1시간을 제외한 근무 4시간**이 필요합니다.

### 남은 근무시간과 퇴근까지 남은 시간

| 항목               | 의미                                                                  |
| ------------------ | --------------------------------------------------------------------- |
| 오늘 총 근무시간   | 출근부터 현재까지의 시간에서 지난 휴게시간을 제외한 값                |
| 오늘 남은 근무시간 | 목표를 채우기 위해 더 일해야 하는 시간. 휴게시간 중에는 줄어들지 않음 |
| 퇴근까지 남은 시간 | 퇴근 가능 시각까지의 시간. 남은 휴게시간과 코어타임 대기 포함         |

예를 들어 **09:00 출근 · 목표 8시간 · 현재 12:00**이면 남은 근무시간은 **5시간**, 퇴근까지 남은 시간은 휴게시간을 포함한 **6시간**입니다.

**08:00 출근 · 목표 6시간 · 정상근무**라면 목표는 15:00에 달성하지만 퇴근 가능 시각은 15:30입니다. 15:10에는 요약에 **초과 근무시간 10분 / 퇴근까지 20분**이 표시됩니다.

목표를 넘기면 요약의 `오늘 남은 근무시간`은 `초과 근무시간`으로 바뀝니다. 실제 경과 근무시간이 9시간을 넘으면 총 근무시간과 함께 일 최대 인정시간인 9시간도 표시합니다.

### 메뉴바 표시

`오늘 근무 → 메뉴바 설정`에서 선택합니다.

- **오늘 총 근무시간:** 휴게시간을 제외한 현재까지의 근무시간
- **퇴근까지 남은 시간:** 퇴근 가능 시각까지의 카운트다운
- **시간 숨기기:** 시간 없이 이모지만 표시

퇴근 가능 시각 이후에는 경과 시간을 `+`로 표시합니다. 예: 1분 경과 시 `+0h 1m`, 20분 경과 시 `+0h 20m`. 시간 표시는 약 1분 간격으로 갱신됩니다.

실제 퇴근을 확정하는 기능은 없으므로, 퇴근 가능 시각 이후에도 앱이 실행 중이면 경과 시간이 계속 늘어납니다.

## 주간 시간 계산

### 기록의 주차와 보관

주간 제목에 월~금 날짜 범위를, 요일 카드에 `월 11/9`처럼 날짜를 표시합니다. 표시된 날짜가 현재 관리 중인 기록의 주차입니다.

새 주가 되어도 수동 기록을 바로 지우지 않습니다. 이전 주 기록이 남아 있으면 안내가 표시되며, 그 기록은 이번 주의 오늘 목표 자동 계산에 사용하지 않습니다.

`보관하고 이번 주 시작`을 누르면 현재 기록과 잠금·고정 상태를 보관한 뒤, 이번 주의 빈 카드로 전환합니다. `보관 기록`을 펼쳐 이전 요일별 인정시간을 확인할 수 있습니다. 보관 기록은 현재 합계와 목표 계산에서 제외됩니다.

보관은 **직전 기록 1개만** 유지합니다. 다시 보관하면 기존 보관 기록을 대체합니다. 주차 정보가 없는 이전 버전의 수동 기록은 임의로 이번 주에 배정하지 않고 `주차 미확인`으로 표시하며, 보관 후 이번 주를 시작할 수 있습니다.

### 인정시간 기준

주간 목표는 월~금 합계 **40시간**이며, 하루 인정시간은 휴가 인정분을 포함해 최대 **9시간**입니다.

| 근무 유형 | 휴가 인정시간 | 합산 방식                 |
| --------- | ------------- | ------------------------- |
| 정상근무  | 없음          | 입력한 근무시간           |
| 연차      | 8시간         | 근무 입력 없이 8시간 인정 |
| 반차      | 4시간         | 근무시간 + 4시간          |
| 반반차    | 2시간         | 근무시간 + 2시간          |

예를 들어 반차를 사용하고 5시간 근무했다면 9시간을 인정합니다. 6시간 근무해도 일 최대 인정시간은 9시간입니다.

요일별 입력 방식은 두 가지입니다.

- **구간:** 출근과 퇴근 시각으로 계산하며, 휴게시간과 겹친 만큼 제외합니다. 정상근무·반차·반반차 모두 직접 입력한 출근은 **08:00~10:30** 범위로 보정합니다. 퇴근은 **정상근무에만 15:30 하한**을 적용하며, 반차·반반차는 그보다 일찍 퇴근할 수 있습니다. 오늘 근무의 실제 출근 입력에는 주간 출근 상한 보정을 적용하지 않으며, flex에서 가져온 실제 기록에도 이 보정 규칙을 적용하지 않습니다.
- **합계:** 휴게시간을 이미 제외한 순수 근무시간을 시간·분으로 입력합니다. 여기서는 휴게시간을 추가로 빼지 않습니다. 반차·반반차의 휴가 인정분도 직접 더하지 않아도 됩니다.

주간 합계는 요일 카드의 `일 인정 시간`을 합산한 값입니다. 40시간까지 남은 시간이 있으면 빨간색으로 표시됩니다.

### 남은 요일 자동 계산

다른 요일을 모두 입력하고 계산할 항목이 하나 남으면, 주 40시간에 필요한 나머지를 자동으로 채웁니다.

- 합계 방식에서는 비어 있는 근무시간을 계산합니다.
- 구간 방식에서는 출근·퇴근 중 하나를 입력하면 반대편 시각을 계산합니다.
- 계산 대상이 여러 개이거나 다른 요일의 입력이 불완전하면 계산을 보류합니다. 근무가 없는 날은 빈칸 대신 합계 `0`을 입력해주세요.
- 자동 계산되는 요일에는 `자동 계산` 표시가 붙습니다.

예를 들어 월~목 인정시간이 32시간이고 금요일 출근을 09:00으로 입력하면, 금요일 퇴근은 휴게시간을 포함한 18:00으로 계산됩니다. 이후 월요일 인정시간을 1시간 늘리면 금요일 퇴근도 1시간 앞당겨집니다.

**자동 계산된 항목을 직접 수정하면 수동 입력으로 전환됩니다.** 이후 다른 요일을 바꿔도 그 값을 덮어쓰지 않습니다. 반대로 자동 계산의 기준이 되는 출근 또는 퇴근을 수정하면 계산 대상 시각은 다시 갱신됩니다.

구간 자동 계산에서는 정상근무·반차·반반차 모두 출근 시각을 **08:00~10:30**으로 역산합니다. **15:30 최소 퇴근 제한은 정상근무에만 적용**하며, 반차·반반차는 그보다 일찍 퇴근할 수 있습니다. 합계 방식은 시각 정보가 없으므로 코어타임으로 시간을 늘리지 않습니다.

고정한 시각, 코어타임, 일 최대 인정시간 또는 당일 종료 한도 때문에 정확히 40시간을 맞출 수 없는 경우에는 주간 요약에 **부족·초과 시간과 이유**를 표시합니다. 이때 직접 지정한 퇴근 시각을 임의로 바꾸지 않으므로 안내를 보고 입력을 조정해주세요.

### 인정시간 8h 맞추기

구간 모드의 핀 메뉴에서 `인정시간 8h 맞추기`를 선택하면, **휴가 인정시간과 실제 근무시간을 합쳐 8시간**이 되도록 계산합니다. 다른 요일의 입력 없이 사용할 수 있습니다.

- 출근·퇴근 중 한 시각을 먼저 핀으로 고정해주세요. 고정한 시각을 유지하고 반대편 시각을 계산합니다. 핀이 없거나 양쪽 모두 고정한 경우에는 버튼이 비활성화됩니다.
- 반차는 근무 4시간, 반반차는 근무 6시간, 정상근무는 근무 8시간을 맞춥니다. 출근 범위 08:00~10:30과 휴게시간을 반영하며, 15:30 최소 퇴근 제한은 정상근무에만 적용합니다.
- 예: 반차를 선택하고 퇴근을 14:00으로 입력한 뒤 퇴근을 고정하고 실행하면 출근은 09:00입니다. 퇴근을 15:30으로 고정하면 출근은 10:30입니다.
- 확정한 요일과 출퇴근을 모두 고정한 요일에서는 사용할 수 없습니다. 합계 모드와 연차에는 표시하지 않습니다.
- 기준 시각을 유지한 채 8시간을 맞출 수 없으면 입력을 변경하지 않고 카드에 이유를 안내합니다.
- 실행 결과는 수동 계획으로 유지하며 주간 자동 역산이 덮어쓰지 않습니다. 다른 요일의 자동 계산은 이 값을 반영해 갱신됩니다.

### 기록 확정과 시간 고정

이미 끝난 근무 기록을 그대로 유지하고 싶다면 자물쇠로 요일 전체를 확정할 수 있습니다. 특정 출근·퇴근 시각만 유지하려면 핀 메뉴를 사용하세요.

| 상황                                      | 사용할 기능           | 유지되는 값과 계산 방식                                    |
| ----------------------------------------- | --------------------- | ---------------------------------------------------------- |
| 월요일 근무를 마쳐 더 바뀌면 안 되는 경우 | 월요일 자물쇠         | 근무시간·휴가 유형·입력 방식 전체 보호                     |
| 금요일 출근을 09:00으로 정한 경우         | 구간 모드의 출근 고정 | 출근은 유지하고, 잠기지 않은 퇴근을 역산                   |
| 금요일 퇴근을 16:00으로 정한 경우         | 구간 모드의 퇴근 고정 | 퇴근은 유지하고, 잠기지 않은 출근을 역산                   |
| 출근과 퇴근을 모두 정한 경우              | 출근·퇴근 모두 고정   | 해당 구간을 유지하고 다른 자동 계산 대상에서 잔여시간 계산 |
| 합계로 입력한 근무시간을 확정하는 경우    | 합계 모드의 자물쇠    | 합계와 휴가 유형을 함께 보호                               |

요일 잠금은 선택 사항입니다. 이미 입력한 기록이 편집이나 자동 계산으로 바뀌지 않게 유지하고 싶을 때 자물쇠를 눌러 확정하세요. 출퇴근 또는 합계 입력이 완료된 날과 연차인 날에 사용할 수 있습니다.

수동으로 입력한 기록은 날짜가 지나도 자동으로 잠기지 않습니다. 반면 flex에서 가져온 완료 기록은 자동으로 잠긴 상태로 표시됩니다.

잠긴 기록은 직접 편집하거나 요일 초기화를 할 수 없습니다. 수정하려면 자물쇠를 눌러 해제해주세요. 단, flex의 자동 잠금은 flex에서 수정된 기록의 재동기화를 허용합니다.

잠긴 요일은 주간 자동 계산 대상에서도 제외됩니다. flex 동기화까지 막고 현재 값을 유지하려면 잠금을 해제한 뒤 다시 잠그세요. 자세한 내용은 [flex 자동 동기화](#자동-동기화)를 참고해주세요.

**개별 시각 고정**은 구간 모드에서만 제공합니다. 고정하려는 시각을 먼저 입력한 다음 핀 메뉴에서 선택하세요. 합계 모드와 연차에는 핀 메뉴가 없으며 자물쇠만 사용합니다. 시각을 개별 고정한 동안에도 휴가 유형·입력 방식 변경과 요일 초기화는 고정을 해제한 뒤 사용할 수 있습니다.

고정한 시각은 ‘정확히 그 시각’을 의미하며, ‘그 시각 이전까지’ 같은 범위 조건은 아닙니다. 반대편 시각을 계산하려면 다른 요일의 입력이 갖춰져야 합니다. 다른 요일이 이미 자동 계산 중이면 그 대상을 유지하므로, 두 요일을 동시에 역산하지 않습니다.

예를 들어 월~목 합계가 32시간인데 금요일 퇴근을 16:00으로 고정하면, 출근 하한 08:00을 적용했을 때 금요일 근무는 휴게시간을 제외한 7시간입니다. 이 경우 퇴근을 임의로 늦추지 않고 **주 40시간까지 1시간 부족**하다고 안내합니다.

잠금은 주간 계산 기록을 보호하는 기능입니다. 오늘 탭의 근무시간 카운트다운을 멈추거나 실제 퇴근을 기록하지는 않습니다. 잠금과 고정 상태는 앱을 다시 실행해도 유지됩니다.

### 오늘 목표와의 연결

입력한 주간 기록은 오늘 목표시간의 자동 계산에도 사용됩니다. 적용 조건과 버튼 사용법은 [주간 기록으로 목표 자동 계산](#주간-기록으로-목표-자동-계산)을 참고해주세요.

오늘 탭에서 입력한 출퇴근 시각은 주간 탭에 별도로 입력할 수 있습니다.
flex 근무기록을 사용한다면 [flex 연결](#flex-연결-베타)에서 자동 동기화를 이용할 수 있습니다.

## 저장과 초기화

입력한 값과 메뉴바 설정은 저장되어 앱을 다시 실행해도 유지됩니다.

- **오늘 근무의 Reset:** 출퇴근 입력을 비우고 기본 목표를 8시간으로 되돌립니다. 주간 자동 목표 조건이 충족되면 제안 목표가 적용될 수 있습니다.
- **주간 탭의 Reset:** 잠금·고정을 포함한 모든 주간 기록과 휴가 유형을 초기화합니다. 주간 기록에 연결된 오늘의 자동 제안도 다시 계산됩니다.
- **요일 카드의 초기화 아이콘:** 해당 요일의 입력과 휴가 유형을 초기화합니다. 잠금·고정 중에는 사용할 수 없습니다. 리셋 직후에는 빈칸을 유지하며, 이후 요일의 시간이나 휴가 유형을 변경하면 자동 계산 조건을 다시 확인합니다.

날짜가 바뀌면 오늘의 출퇴근 입력은 초기화되며, 메뉴바 표시 설정은 유지됩니다. 주간 기록을 직접 관리한다면 새 주 안내의 `보관하고 이번 주 시작`을 사용하세요. 기록을 보관하지 않고 지우려면 주간 탭의 `Reset`을 사용할 수 있습니다.

## flex 연결 (베타)

### 처음 연결하기

1. 상단 오른쪽 끝의 flex 연결을 누릅니다. 연결 후에는 같은 위치에 flex 동기화 버튼이 표시됩니다.
2. 로그인 창에서 flex에 로그인해주세요.
3. 첫 연결이 완료되면 자동 동기화를 켜고 이번 주 근무기록을 가져옵니다.

### 자동 동기화

주간 화면에 **flex 자동 동기화**가 표시되면, 메뉴바 앱이 실행 중일 때 약 3분마다 조회합니다. flex에서 평소처럼 퇴근하면, Jibegaza가 같은 날 근무 중 상태를 한 번 확인한 경우 종료된 근무기록을 자동 반영합니다. 앱을 다시 실행하거나 Mac이 잠자기에서 깨어날 때도 이번 주의 지난 평일 기록을 확인합니다. 즉시 확인하려면 **동기화**를 누르세요.

상단의 flex 동기화 버튼은 오늘·주간 탭에서 공통으로 사용합니다. 오늘 탭에는 출근 시각 동기화 결과와 마지막 동기화 시각이 표시됩니다. 출근 기록이 없거나 조회에 실패한 경우도 안내합니다.

flex 출근 시각이 반영되면 메뉴바 시간 표시도 활성화됩니다. 자동 동기화 설정과 연결 해제는 flex 버튼 왼쪽의 더보기 메뉴에서 관리할 수 있습니다.

완료된 날짜는 휴게시간을 뺀 flex 실제 근무시간으로 갱신합니다. 잠금 없는 수동 계획도 실제 기록으로 바뀌며, 이후 flex에서 수정한 시간도 다시 반영합니다. 미래 날짜와 오늘 근무 중인 계획은 유지합니다.

가져온 카드에는 `flex`가 표시되며, 하루 인정시간은 최대 9시간입니다. flex 기록은 처음부터 잠긴 상태로 표시되지만, flex에서 수정한 시간은 계속 동기화됩니다. 직접 편집하려면 잠금을 해제하세요. flex 덮어쓰기까지 막으려면 잠금을 해제한 뒤 다시 잠그세요.

사용자가 직접 잠근 날짜, 시간을 고정한 날짜, 휴가가 설정된 날짜와 지원하지 않는 근무 유형은 건너뜁니다. 조회 결과와 제외 사유는 **상세 정보**에서 확인할 수 있습니다.

이전 주 기록이 모두 같은 계정에서 가져온 flex 기록이고, 사용자가 직접 잠그거나 고정한 날짜가 없다면 새 주 기록을 반영할 때 기존 기록을 보관하고 주간 카드를 교체합니다. 수동 기록이 남아 있거나 주차 확인 안내가 나오면 **보관하고 이번 주 시작**으로 전환할 수 있습니다. 계정 확인 안내가 나오면 기록을 확인한 뒤 주간 탭에서 **Reset**을 사용하세요.

### 로그인과 연결 관리

- **자동 동기화 끄기:** 상단 flex 버튼 옆 더보기 메뉴에서 **자동 동기화**를 끕니다. 필요할 때 **동기화** 버튼으로 조회할 수 있습니다.
- **로그인 유지:** 앱은 로그인 세션을 저장하고, 만료되면 자동 갱신을 먼저 시도합니다. flex가 다시 인증을 요구하면 **flex 다시 로그인**을 누르세요. 재로그인 시 선택한 자동 동기화 설정이 유지됩니다.
- **연결 해제:** Chrome이나 Safari에서 쿠키를 삭제해도 Jibegaza의 flex 세션은 남아 있습니다. 앱의 로그인 정보를 지우려면 flex 더보기 메뉴에서 **연결 해제**를 누르세요.

회사 로그인 정책에 따라 앱 안에서 로그인이 제한될 수 있으며, flex 내부 API가 변경되면 동기화가 중단될 수 있습니다.

## 앱 업데이트

업데이트를 지원하는 버전을 한 번 설치하면 이후에는 앱 상단의 **새 버전 확인**으로 새 버전을 확인하고, 업데이트 창에서 다운로드·설치·재실행할 수 있습니다. 앱 실행 중에는 약 1시간 간격으로 자동 확인하며, 새 버전을 발견하면 업데이트 창으로 안내합니다. 배포 순간 실시간 푸시 알림은 아닙니다. 앱은 `/Applications` 등 쓰기 가능한 위치에 복사해서 사용하세요. ZIP이나 디스크 이미지 안에서 바로 실행하면 업데이트가 제한될 수 있습니다.

새 버전을 발견하면 상단 버튼 문구가 **새 버전 업데이트**로 바뀌고, 다운로드·압축 해제가 완료되면 **재시작하여 업데이트**로 표시됩니다. 버튼을 누르면 업데이트 창이 열립니다.

업데이트 기능이 없는 이전 버전은 업데이트를 지원하는 버전을 한 번 직접 설치해야 합니다. 최초 실행 시 macOS의 보안 경고가 나타나면 앞의 [앱 실행 방법](#앱-실행-방법)을 참고해주세요.
