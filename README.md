# Jibegaza MenuBar

오늘 얼마나 일했는지, 언제 퇴근할 수 있는지 macOS 메뉴바에서 확인하는 근무 시간 계산기입니다. `오늘 근무`에서 하루의 근무 계획을 세우고, `주간 시간 계산`에서 월~금의 인정시간을 합산할 수 있습니다.

## 앱 실행 방법
설정 - 개인정보 보호 및 보안 - 보안 - `그래도 열기` 클릭

## 시작하기

1. `주간 시간 계산`에서 요일별 근무시간과 휴가 유형을 입력합니다. 오늘 반차·반반차를 사용한다면 오늘 요일의 유형도 변경해주세요.
2. `오늘 근무`에서 목표 근무시간과 출근 시각을 입력합니다.
3. 이미 근무를 마친 요일은 자물쇠로 기록을 확정합니다. 특정 출근·퇴근 시각을 유지해야 한다면 구간 모드의 핀 메뉴를 사용합니다.
4. 메뉴바 설정에서 `퇴근까지 남은 시간` 또는 `오늘 총 근무시간`을 선택합니다.

주간 입력 없이 오늘 근무만 사용할 수도 있습니다. 이 경우 평일의 오늘 근무는 기본적으로 정상근무 기준으로 계산됩니다.

## 오늘 근무

### 목표시간과 출퇴근 시각

목표 근무시간은 휴게시간을 제외한 순수 근무시간입니다. 기본 목표는 8시간이며, `6h`, `7h`, `8h`, `9h`, `직접입력` 중에서 선택할 수 있습니다.

| 입력 방식 | 동작 |
| --- | --- |
| 시간 프리셋에서 출근 수정 | 목표시간을 유지하고 퇴근 시각 계산 |
| 시간 프리셋에서 퇴근 수정 | 목표시간을 유지하고 출근 시각 역산 |
| 직접입력에서 목표 시간·분 수정 | 출근 시각을 유지하고 퇴근 시각 계산 |
| 직접입력에서 출근 또는 퇴근 수정 | 반대편 시각을 유지하고 목표 시간·분 계산 |

예를 들어 직접입력 상태에서 `09:00~18:00`의 퇴근을 `17:00`으로 바꾸면, 출근은 09:00으로 유지되고 목표시간은 점심을 제외한 7시간으로 바뀝니다.

출근 시각은 **08:00부터** 입력할 수 있습니다. 07:45처럼 이전 시각을 선택하면 08:00으로 보정됩니다. 프리셋 역산 결과가 08:00 이전이면 출근을 08:00으로 맞추고, 목표시간을 유지하도록 퇴근도 다시 계산합니다.

### 점심시간과 코어타임

점심시간은 **12:30~13:30**입니다. 근무 구간과 실제 겹치는 만큼만 제외합니다. 점심시간을 지나지 않는 근무에는 1시간을 일괄 차감하지 않습니다.

정상근무의 코어타임은 **10:30~15:30**입니다.

- 퇴근 가능 시각은 15:30보다 빨라지지 않습니다.
- 출근 시각을 자동 역산할 때는 10:30을 넘기지 않습니다.
- 직접 입력한 10:30 이후 출근은 그대로 유지합니다.
- 코어타임 때문에 퇴근이 늦춰져도 직접 정한 목표시간은 늘어나지 않습니다.

오늘의 근무 유형은 `주간 시간 계산`에 입력한 해당 요일의 휴가 유형을 따릅니다. **반차·반반차·연차에는 오늘 근무의 코어타임을 적용하지 않습니다.** 08:00 출근 하한과 점심시간 계산은 그대로 적용됩니다.

### 남은 근무시간과 퇴근까지 남은 시간

| 항목 | 의미 |
| --- | --- |
| 오늘 총 근무시간 | 출근부터 현재까지의 시간에서 지난 점심시간을 제외한 값 |
| 오늘 남은 근무시간 | 목표를 채우기 위해 더 일해야 하는 시간. 점심 중에는 줄어들지 않음 |
| 퇴근까지 남은 시간 | 퇴근 가능 시각까지의 시간. 남은 점심시간과 코어타임 대기 포함 |

예를 들어 **09:00 출근 · 목표 8시간 · 현재 12:00**이면 남은 근무시간은 **5시간**, 퇴근까지 남은 시간은 점심을 포함한 **6시간**입니다.

**08:00 출근 · 목표 6시간 · 정상근무**라면 목표는 15:00에 달성하지만 퇴근 가능 시각은 15:30입니다. 15:10에는 요약에 **초과 근무시간 10분 / 퇴근까지 20분**이 표시됩니다.

목표를 넘기면 요약의 `오늘 남은 근무시간`은 `초과 근무시간`으로 바뀝니다. 실제 경과 근무시간이 9시간을 넘으면 총 근무시간과 함께 일 최대 인정시간인 9시간도 표시합니다.

### 메뉴바 표시

`오늘 근무 → 메뉴바 설정`에서 선택합니다.

- **오늘 총 근무시간:** 점심을 제외한 현재까지의 근무시간
- **퇴근까지 남은 시간:** 퇴근 가능 시각까지의 카운트다운
- **시간 숨기기:** 시간 없이 이모지만 표시

퇴근 가능 시각을 20분 지나면 메뉴바에 `+0h 20m`처럼 표시됩니다. 이 값은 **퇴근 가능 시각 이후의 경과 시간**으로, 요약의 **목표 대비 초과 근무시간**과 다를 수 있습니다.

시간 표시는 약 1분 간격으로 갱신됩니다. 실제 퇴근을 확정하는 기능은 없으므로, 퇴근 가능 시각 이후에도 앱이 실행 중이면 경과 시간이 계속 늘어납니다.

## 주간 시간 계산

### 인정시간 기준

주간 목표는 월~금 합계 **40시간**이며, 하루 인정시간은 휴가 인정분을 포함해 최대 **9시간**입니다.

| 근무 유형 | 휴가 인정시간 | 합산 방식 |
| --- | --- | --- |
| 정상근무 | 없음 | 입력한 근무시간 |
| 연차 | 8시간 | 근무 입력 없이 8시간 인정 |
| 반차 | 4시간 | 근무시간 + 4시간 |
| 반반차 | 2시간 | 근무시간 + 2시간 |

예를 들어 반차를 사용하고 5시간 근무했다면 9시간을 인정합니다. 6시간 근무해도 일 최대 인정시간은 9시간입니다.

요일별 입력 방식은 두 가지입니다.

- **구간:** 출근과 퇴근 시각으로 계산하며, 점심시간과 겹친 만큼 제외합니다. 08:00 이전 출근은 08:00으로 보정합니다.
- **합계:** 휴게시간을 이미 제외한 순수 근무시간을 시간·분으로 입력합니다. 여기서는 점심시간을 추가로 빼지 않습니다. 반차·반반차의 휴가 인정분도 직접 더하지 않아도 됩니다.

주간 합계는 요일 카드의 `일 인정 시간`을 합산한 값입니다. 40시간까지 남은 시간이 있으면 빨간색으로 표시됩니다.

### 남은 요일 자동 계산

다른 요일을 모두 입력하고 계산할 항목이 하나 남으면, 주 40시간에 필요한 나머지를 자동으로 채웁니다.

- 합계 방식에서는 비어 있는 근무시간을 계산합니다.
- 구간 방식에서는 출근·퇴근 중 하나를 입력하면 반대편 시각을 계산합니다.
- 계산 대상이 여러 개이거나 다른 요일의 입력이 불완전하면 계산을 보류합니다. 근무가 없는 날은 빈칸 대신 합계 `0`을 입력해주세요.
- 자동 계산되는 요일에는 `자동 계산` 표시가 붙습니다.

예를 들어 월~목 인정시간이 32시간이고 금요일 출근을 09:00으로 입력하면, 금요일 퇴근은 점심을 포함한 18:00으로 계산됩니다. 이후 월요일 인정시간을 1시간 늘리면 금요일 퇴근도 1시간 앞당겨집니다.

**자동 계산된 항목을 직접 수정하면 수동 입력으로 전환됩니다.** 이후 다른 요일을 바꿔도 그 값을 덮어쓰지 않습니다. 반대로 자동 계산의 기준이 되는 출근 또는 퇴근을 수정하면 계산 대상 시각은 다시 갱신됩니다.

구간 자동 계산에도 08:00 출근 하한과 정상근무 코어타임을 반영합니다. 반차·반반차에는 코어타임을 적용하지 않습니다. 합계 방식은 시각 정보가 없으므로 코어타임으로 시간을 늘리지 않습니다.

고정한 시각, 코어타임, 일 최대 인정시간 또는 당일 종료 한도 때문에 정확히 40시간을 맞출 수 없는 경우에는 주간 요약에 **부족·초과 시간과 이유**를 표시합니다. 이때 직접 지정한 퇴근 시각을 임의로 바꾸지 않으므로 안내를 보고 입력을 조정해주세요.

### 기록 확정과 시간 고정

이미 끝난 근무 기록은 **자물쇠로 요일 전체를 확정**하고, 앞으로의 출근·퇴근 계획 중 특정 시각만 유지하려면 **핀 메뉴로 시각을 고정**합니다.

| 상황 | 사용할 기능 | 유지되는 값과 계산 방식 |
| --- | --- | --- |
| 월요일 근무를 마쳐 더 바뀌면 안 되는 경우 | 월요일 자물쇠 | 근무시간·휴가 유형·입력 방식 전체 보호 |
| 금요일 출근을 09:00으로 정한 경우 | 구간 모드의 출근 고정 | 출근은 유지하고, 잠기지 않은 퇴근을 역산 |
| 금요일 퇴근을 16:00으로 정한 경우 | 구간 모드의 퇴근 고정 | 퇴근은 유지하고, 잠기지 않은 출근을 역산 |
| 출근과 퇴근을 모두 정한 경우 | 출근·퇴근 모두 고정 | 해당 구간을 유지하고 다른 자동 계산 대상에서 잔여시간 계산 |
| 합계로 입력한 근무시간을 확정하는 경우 | 합계 모드의 자물쇠 | 합계와 휴가 유형을 함께 보호 |

**요일 잠금**은 출퇴근 또는 합계 입력이 완료된 날과 연차인 날에 사용할 수 있습니다. 날짜가 지났다고 자동으로 잠기지는 않습니다. 잠긴 요일은 자동 계산 대상에서 제외되며 직접 편집과 요일 초기화도 할 수 없습니다. 수정하려면 자물쇠를 다시 눌러 해제해주세요.

**개별 시각 고정**은 구간 모드에서만 제공합니다. 고정하려는 시각을 먼저 입력한 다음 핀 메뉴에서 선택하세요. 합계 모드와 연차에는 핀 메뉴가 없으며 자물쇠만 사용합니다. 시각을 개별 고정한 동안에도 휴가 유형·입력 방식 변경과 요일 초기화는 고정을 해제한 뒤 사용할 수 있습니다.

고정한 시각은 ‘정확히 그 시각’을 의미하며, ‘그 시각 이전까지’ 같은 범위 조건은 아닙니다. 반대편 시각을 계산하려면 다른 요일의 입력이 갖춰져야 합니다. 다른 요일이 이미 자동 계산 중이면 그 대상을 유지하므로, 두 요일을 동시에 역산하지 않습니다.

예를 들어 월~목 합계가 32시간인데 금요일 퇴근을 16:00으로 고정하면, 출근 하한 08:00을 적용했을 때 금요일 근무는 점심을 제외한 7시간입니다. 이 경우 퇴근을 임의로 늦추지 않고 **주 40시간까지 1시간 부족**하다고 안내합니다.

잠금은 주간 계산 기록을 보호하는 기능입니다. 오늘 탭의 근무시간 카운트다운을 멈추거나 실제 퇴근을 기록하지는 않습니다. 잠금과 고정 상태는 앱을 다시 실행해도 유지됩니다.

### 오늘 목표와의 연결

주간 기록을 바탕으로 **이번 주 마지막 근무일이 오늘**이고 다른 요일의 입력이 갖춰지면, 오늘 필요한 목표시간을 자동으로 제안할 수 있습니다. 연차인 날은 마지막 근무일에서 제외하며, 휴가 인정분과 일 최대 인정시간도 반영합니다.

자동 제안과 별개로 오늘 목표를 직접 정할 수 있습니다. 자동계산이 가능한 상태에서는 직접입력 영역의 `자동계산` 버튼으로 제안값을 다시 적용할 수 있습니다.

오늘의 출퇴근 입력은 주간 카드에 자동으로 기록되지 않습니다. 주간 합계에 반영할 근무시간은 주간 탭에 별도로 입력해주세요.

## 저장과 초기화

입력한 값과 메뉴바 설정은 저장되어 앱을 다시 실행해도 유지됩니다.

- **오늘 근무의 Reset:** 출퇴근 입력을 비우고 기본 목표를 8시간으로 되돌립니다. 주간 자동 목표 조건이 충족되면 제안 목표가 적용될 수 있습니다.
- **주간 탭의 Reset:** 잠금·고정을 포함한 모든 주간 기록과 휴가 유형을 초기화합니다. 주간 기록에 연결된 오늘의 자동 제안도 다시 계산됩니다.
- **요일 카드의 초기화 아이콘:** 해당 요일의 입력과 휴가 유형을 초기화합니다. 잠금·고정 중에는 사용할 수 없습니다. 초기화한 요일은 새로 입력하기 전까지 자동 계산에서 제외됩니다.

날짜가 바뀌면 오늘의 출퇴근 입력과 메뉴바 표시 설정은 초기화됩니다. 주간 기록은 자동으로 새 주 기록으로 교체되지 않으므로 새 주를 시작할 때 주간 탭의 `Reset`을 사용해주세요.
