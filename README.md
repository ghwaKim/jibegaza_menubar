# Jibegaza MenuBar

macOS 메뉴바에서 바로 확인하는 근무 시간 계산기입니다.

## 앱 실행 방법

설정 - 개인정보 보호 및 보안 - 보안 - `그래도 열기` 클릭

## 주요 기능

### 메뉴바 표시

- 메뉴바에서 오늘 근무 상태를 바로 확인할 수 있습니다.
- 표시 옵션은 `오늘 근무 - 메뉴바 설정`에서 선택합니다.
- 지원 옵션:
  - `⏱️ 오늘 총 근무시간`: 목표시간과 별개로 오늘의 총 근무시간이 표시됩니다.
  - `⏳ 오늘 남은 근무시간`: 목표시간을 기준으로 오늘의 남은 근무시간이 표시됩니다.
  - `🏃‍♂️ 시간 숨기기`: 메뉴바에는 시간 없이 이모지만 표시됩니다.

### 오늘 근무

- 목표 근무 시간을 `6h`, `7h`, `8h`, `9h`, `직접입력` 중에서 선택할 수 있습니다.
- 주간 근무 시간을 입력한 경우 남은 시간을 자동으로 계산할 수 있습니다.
- 기본 목표 근무 시간은 `8h`입니다.
- 기본 출근 시간은 `오전 8시`입니다.
- 출근 시간을 입력하면 목표 시간에 맞춰 퇴근 시간이 자동 계산됩니다.
- 퇴근 시간을 입력하면 목표 시간에 맞춰 출근 시간이 자동 계산됩니다.
- 휴게 시간은 고정 `60분` (12:30 ~ 13:30)이며 실제 근무 시간에서 자동 차감됩니다.
- `직접입력` 선택 시에만 시간/분 입력 필드가 표시됩니다.
- 자동 계산 가능한 경우 `직접입력` 영역에서 `[자동계산]` 버튼으로 남은 시간을 다시 불러올 수 있습니다.
- 오늘 탭에서는 다음 정보를 확인할 수 있습니다.
  - 목표 근무 시간
  - 출근 시간
  - 퇴근 시간
  - 오늘 총 근무시간
  - 오늘 남은 근무시간
- `오늘 총 근무시간`이 9시간이 넘더라도 일 최대 근무 인정시간은 9시간입니다.
- `Reset`을 누르면 오늘 출근/퇴근 시간이 비어 있는 상태로 돌아가고, 목표 근무 시간은 `8h`로 초기화됩니다.
- 날짜가 자정 이후로 바뀌면 오늘 근무 상태는 자동으로 초기화됩니다.

### 주간 시간 계산

- 월~금 기준으로 주간 근무 시간을 계산합니다.
- 주간 목표 시간은 고정 `40시간`입니다.
- 주간 탭에서는 다음 정보를 확인할 수 있습니다.
  - 주간 합계
  - 40시간까지 남은 시간
  - 요일별 일 인정 시간
- 각 요일은 다음 상태를 선택할 수 있습니다.
  - 정상근무
  - 연차
  - 반차
  - 반반차
- 각 요일은 다음 입력 방식을 선택할 수 있습니다.
  - 구간: 시작 시간 `~` 종료 시간
  - 합계: 직접 `시간`, `분` 입력
- 연차는 `8시간`, 반차는 `4시간`, 반반차는 `2시간`으로 인정됩니다.
- 일 인정 시간은 최대 `9시간`까지만 반영됩니다.
- 점심 시간 `12:30 ~ 13:30`과 겹치는 시간은 실제 근무 시간에서 차감됩니다.
- 각 요일의 `Delete` 버튼으로 해당 요일 입력값만 초기화할 수 있습니다.
- 주간 탭에서 `Reset`을 누르면 주간 데이터만 초기화됩니다.

## 개발 실행

```bash
swift run
```

실행하면 Dock 아이콘 없이 메뉴바에 앱이 표시됩니다.

## 앱 빌드

공유용 앱 번들과 zip 파일을 만들려면 아래 명령을 실행합니다.

```bash
chmod +x scripts/build_app.sh
./scripts/build_app.sh
```

빌드가 끝나면 `dist/`에 다음 파일이 생성됩니다.

- `dist/Jibegaza MenuBar.app`
- `dist/Jibegaza MenuBar.zip`
- `dist/앱_실행_방법.png`
